Les missions d'Albert

Vingt missions progressives pour apprendre à programmer les déplacements d’Albert et récupérer des puces d’intelligence artificielle (IA). Départ (0, 2), objectif (2, 1).

Le laboratoire

Albert attend vos instructions.

Les coordonnées commencent à (0, 0) en haut à gauche.

Un indice, sans donner la réponse

Votre programme

Atelier Python réel : variables, listes, fonctions et tests ↗

Écris des instructions de déplacement, puis découvre les conditions if, les boucles bornées for, les boucles non bornées while et les variables de type entier.

Mots-clés violets · commandes bleues · nombres orange · commentaires verts. Tabulation : quatre espaces.




Limite du prototype : ce parcours interprète un sous-ensemble pédagogique de la syntaxe Python (instructions, conditions if / elif / else, boucles for et while, affectations et compteurs). Il n’exécute pas encore du Python général avec Pyodide.


Aucune donnée personnelle, aucun appel à l'API Albert.
