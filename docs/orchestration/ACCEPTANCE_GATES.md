# Portes de validation G0→G5

- G0 — architecture, risques, lexique, identité, audit prototype, contrats cohérents; décision humaine requise.
- G1 — compilation stricte, API simulée, gestion des erreurs, secrets protégés, CI reproductible.
- G2 — fidélité des captures, états de MicroAlbert, thèmes clair/sombre/projecteur et accessibilité.
- G3 — génération Albert robuste, Markdown sûr, finish_reason contrôlé, modes Élève/Enseignant/Audit.
- G4 — éditeur Python exécutable, tests déterministes, prévention des blocages, indices gradués.
- G5 — RGPD, autorisations, sécurité, performance, pilote, recette humaine avant toute publication.

Chaque porte comporte : prérequis vérifiables, preuves horodatées, anomalies ouvertes, décision VALIDABLE / À_CORRIGER / BLOQUÉE. Pas de succès implicite.
