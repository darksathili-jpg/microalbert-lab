Installer Thonny

Thonny est un éditeur gratuit pour écrire, enregistrer et exécuter des programmes Python sur ton ordinateur. Les versions proposées pour Windows et macOS incluent Python.

Site officiel et téléchargements à jour

Aller aux étapes pour utiliser Thonny sans installation

Installer sur ton ordinateur

Windows 10 ou 11

  1. Dans Paramètres → Système → À propos de (ou Informations système), repère le Type du système. Choisis x64 pour Intel ou AMD, ou ARM64 pour un processeur ARM.
  2. Télécharge puis ouvre le fichier .exe. Suis les instructions de l’installateur.
  3. Ouvre Thonny depuis le menu Démarrer.
  • Télécharger l’installateur Windows x64
  • Télécharger l’installateur Windows ARM64

macOS

Ouvre À propos de ce Mac dans le menu Apple. Choisis le paquet .pkg pour puce Apple ou pour processeur Intel, puis ouvre-le et suis les étapes. Lance ensuite Thonny depuis Applications.

  • Télécharger Thonny pour un Mac avec puce Apple
  • Télécharger Thonny pour un Mac Intel

Linux

L’installateur officiel utilise le Python 3 déjà présent sur ton ordinateur. Sur Debian, Ubuntu ou Linux Mint, tu peux aussi passer par le gestionnaire de paquets de ta distribution.

Voir les instructions officielles pour Linux

Utiliser Thonny portable

Cette archive pour Windows 10 ou 11 contient Thonny et Python. Après l’avoir extraite, tu peux écrire et exécuter des programmes hors ligne, sans installation, depuis un dossier ou une clé USB.

Télécharger Thonny portable (.zip)

L’archive est prévue pour les processeurs Intel ou AMD x64. Sur Windows ARM64, elle utilise l’émulation x64.

  1. Dans l’Explorateur de fichiers, fais un clic droit sur l’archive .zip et choisis Extraire tout.
  2. Choisis un dossier où tu peux enregistrer des fichiers. Pour emporter Thonny sur une clé USB, extrais l’archive dans un dossier de la clé ou copies-y le dossier décompressé en entier.
  3. Dans le dossier décompressé, double-clique sur thonny.exe.

Sur un poste du lycée, vérifie avec ton enseignant que l’exécution depuis ce dossier ou cette clé est autorisée.

Documentation officielle du mode portable

Vérifier que Python fonctionne

Saisis cette instruction dans l’éditeur de Thonny, enregistre le fichier sous bonjour.py, puis appuie sur F5 ou utilise le menu Exécuter.

print("Bonjour, MicroAlbert !")

Le texte Bonjour, MicroAlbert ! doit s’afficher dans la console, sous l’éditeur.

Ouvrir un programme écrit dans MicroAlbert

Dans ton défi, utilise le bouton Télécharger le programme (flèche vers le bas) au-dessus de l’éditeur. Dans Thonny, fais Fichier → Ouvrir, sélectionne le fichier .py téléchargé, puis exécute-le avec F5.
