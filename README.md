# MicroAlbert Lab

Laboratoire pédagogique expérimental pour la spécialité NSI (Première et Terminale), utilisant Albert API.

**État : préparation G0 — aucune version destinée aux élèves n'est validée.**

L'architecture, le contrat graphique et les exigences pédagogiques sont élaborés sur une branche de travail. Le dépôt ne doit contenir ni clé API, ni donnée personnelle d'élève.

Aucune publication de l'application n'est autorisée avant validation humaine des portes de recette.
