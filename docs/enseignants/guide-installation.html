1. Accéder au service

Consultez le portail officiel Albert API, puis suivez le parcours professionnel proposé. L'accès à Nuage et l'accès à l'API sont distincts.

Créez une clé dans votre espace autorisé et conservez-la dans un emplacement sécurisé. Si elle ne peut plus être affichée, utilisez la procédure officielle de création/remplacement.

2. Charger la clé dans PowerShell

Copiez d'abord votre clé depuis son emplacement sécurisé. Le raccourci Ctrl+V peut afficher ^V dans certains terminaux : il n'est pas nécessaire de retaper la clé.

$env:ALBERT_API_KEY = (Get-Clipboard).Trim()
[string]::IsNullOrWhiteSpace($env:ALBERT_API_KEY)
Set-Clipboard -Value ""

Le test doit afficher False. Cette variable est temporaire et disparaît lorsque la session PowerShell est fermée. Le presse-papiers peut être historisé : préférez un gestionnaire de secrets lorsque disponible.

3. Tester Albert API

$headers = @{ Authorization = "Bearer $env:ALBERT_API_KEY" }
Invoke-RestMethod -Method Get -Uri "https://albert.api.etalab.gouv.fr/v1/models" -Headers $headers |
  Select-Object -ExpandProperty data |
  Select-Object id

Une liste d'identifiants confirme l'accès. Tous les modèles ne prennent pas en charge la conversation : les modèles d'OCR, d'embedding et de reranking ne sont pas à choisir pour ce test.

4. Lancer le prototype V0.1

Décompressez le prototype dans un dossier contenant server.py et index.html. Dans la même session PowerShell que celle où la clé est chargée, placez-vous dans ce dossier :

py --version
py server.py

Ouvrez http://127.0.0.1:8765. Arrêtez le serveur avec Ctrl+C. Ne l'exposez pas sur le réseau de l'établissement.
