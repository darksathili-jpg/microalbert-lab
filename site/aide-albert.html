Découvrir l’IA Albert

Albert donne accès à plusieurs modèles d’intelligence artificielle (IA) via un service de la Direction interministérielle du numérique (DINUM). Tu peux essayer ces modèles dans un navigateur. Pour les connecter à une application, il faut une clé API qui autorise l’application à utiliser l’interface de programmation.

Créer une clé API

  1. Ouvre la console officielle et identifie-toi avec ProConnect et ton compte professionnel.
  2. Dans le menu API Keys (« Clés API »), donne un nom à la clé, par exemple MicroAlbert, choisis une date d’expiration, puis crée-la.
  3. Enregistre la clé dès sa création dans un emplacement sécurisé. Vérifie le quota de ton compte pour le modèle choisi avant un premier essai.

Utiliser ta clé dans MicroAlbert

Sur GitHub Pages, l’atelier fournit une aide locale. Pour un essai enseignant avec Albert, utilise le serveur de l’atelier local. Sous Windows, ouvre 02-Configurer-Albert.cmd, saisis la clé dans la fenêtre de configuration masquée, indique le modèle, puis relance l’atelier. Ouvre Aide avec Albert depuis un défi.

Garde la clé côté serveur. Pour ton premier essai, envoie une tentative Python fictive et vérifie l’extrait avant de le transmettre.
